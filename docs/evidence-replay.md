# Evidence packs and replay

Run `honestenv evidence-run TASK --out PACK --agent oracle --expected must_pass` to run one explicitly selected Harbor task. The command retains the task snapshot when execution fails, the reward cannot be interpreted, or its conclusion differs from the expected label. Use `--confirmed-defect` to retain a run regardless of its conclusion. `unknown` does not classify a valid reward as a failure. The destination must not already exist.

The pack contains `task/`, a W06 `report.json`, `replay.json`, and captured Harbor `stdout.txt` and `stderr.txt`. The report records the raw reward, binary mapping, versions and relative references. The replay metadata identifies the agent and hashes the task snapshot. Run `honestenv replay PACK` from any directory with honestenv, Harbor 0.27.0 and Docker installed. Replay checks the snapshot hash and invokes Harbor using the bundled task. It prints the replay reward and exits nonzero when Harbor fails or no valid numeric reward is available. Compare the resulting score with the stored report separately.

No environment variables are collected for the pack. The caller must explicitly select a task and inspect it and its outputs for secrets before sharing. The command rejects known sensitive filenames and common credential patterns in task files, output and report. This is a limited safeguard, not proof that arbitrary unknown credentials are absent. It fails instead of retaining detected sensitive content. Harbor and task execution may access the host environment under their own execution rules. Replay executes the bundled task; only replay trusted packs.
